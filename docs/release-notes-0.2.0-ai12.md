# HyperPortal v0.2.0-ai12

## Segmentation panel glass-material refinement

- Restore the original icon glyphs, icon-button rendering and AI button appearance; this release changes the glass surface, not the icon artwork.
- Replace the pale full-screen scrim with a subtle cool neutral dim layer to preserve the colors and contrast of the app behind the panel.
- Increase rounded backdrop blur and use a restrained milky white/blue frost layer for a more tactile frosted-glass surface.
- Reduce diffuse lower-edge shading and remove the extra selected-word text shadow.
- Keep segmentation, selection, extraction and action behavior unchanged.
